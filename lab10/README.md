# Зертханалық жұмыс №10

## Тақырыбы: Java Applet және графикалық интерфейс

### 📌 Жұмыстың мақсаты:

Java Applet технологиясын пайдаланып графикалық интерфейс элементтерін құру және оқиғаларды өңдеу.

### 📂 Құрамы:

Жоба 10 есептен тұрады:

1. Фигуралар салу
2. Батырма арқылы мәтін шығару
3. TextField қолдану
4. Түстерді өзгерту
5. Координата бойынша фигура салу
6. Mouse Event
7. Key Event
8. Калькулятор
9. Анимация
10. Checkbox қолдану

### ⚠️ Маңызды ескерту:

Java Applet қазіргі Java нұсқаларында (JDK 11 және жоғары) қолдау көрсетілмейді.
Сондықтан жоба кодтары заманауи ортада іске қосылмауы мүмкін.

Жобаны іске қосу үшін:

* Java JDK 8 қажет
* AppletViewer қолданылуы тиіс

### 🛠 Қолданылған технология:

* Java
* AWT
* Applet
